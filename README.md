# jQValidator.js


> 可以兼容现代主流浏览器  **version 2.8.0**


## 2024.07.23 2.8.0版本新增修改如下：

1. 修复优化:
* 一个页面多个表单时，输入框验证不起效Bug问题
* 优化表单关于radio和checkbox重置功能

2. 新增功能：
* 如果当前$form没有id，则给form添加随机id
* 新增getFormDatas()方法：可以获取当前表单数据序列组
* 新增动态文本框添加html方法，AddFieldHtml()
* 新增动态文本框移除html方法，removeFieldHtml()
